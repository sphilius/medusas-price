How to playtest (start here)
  1. Pick the milestone you're testing in the Playtest tab (the newest one is selected for you).
  2. Do the Get set up steps in order, then play.
  3. Tick boxes and pick answers as you go. Everything saves by itself; nothing to submit.
  4. Answer open design questions in the Decisions tab. Drop any other thought in Feedback.
  5. When you're done, tell Claude: "read my playtest answers". Claude updates this guidebook from them.
